How to use a module

  1. Define the decision and comparator before selecting an analytic method.
  2. Review the module README and synthetic input structure.
  3. Record the local data source, evidence cut-off, system version, package environment, and assumptions.
  4. Run verification checks and compare results with an independent calculation where proportionate.
  5. Interpret outputs alongside affordability, subgroup effects, implementation, governance, and mandatory safeguards.
  6. Preserve the result, code version, input version, review date, and conditions that would change the decision.
