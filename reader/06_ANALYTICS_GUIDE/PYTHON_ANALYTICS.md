# Python Analytics

The Python Analytics layer contains 39 reproducible modules aligned with the current book structure. Each module includes a standard Python script, Jupyter notebook, synthetic inputs, editable spreadsheet inputs, example outputs, and documentation.

## When to use this layer

Use a module when the institutional question requires transparent quantitative analysis that cannot be completed reliably through a narrative form alone. Examples include local validation, calibration, decision-curve analysis, lifecycle costing, budget impact, simulation, probabilistic sensitivity analysis, value of information, forecasting, optimization, monitoring, and circularity measurement.

## Recommended workflow

1. Begin with the decision problem, comparator, population, setting, and accountable owner.
2. Review the aligned book chapter and worked case.
3. Read the module README and inspect the synthetic inputs before running code.
4. Create a governed local copy and replace synthetic data only with authorized, documented inputs.
5. Preserve package versions, random seeds, data provenance, system version, assumptions, and output files.
6. Compare code outputs with spreadsheet or hand checks where proportionate.
7. Record uncertainty, subgroup effects, limitations, decision conditions, and the next review date.
8. Archive a static decision output; an interactive notebook alone is not a sufficient institutional record.

## Browser navigation

The GitHub Pages `Python Analytics` view supports filtering by chapter, method, related worked case, and keyword. The browser is a navigation layer; scripts, notebooks, spreadsheets, data, and example outputs remain the canonical source files.

## Data and safety

Do not place identifiable patient information, credentials, private keys, confidential contracts, or uncontrolled institutional data in public notebooks or repository copies. The included data are synthetic unless explicitly stated.
