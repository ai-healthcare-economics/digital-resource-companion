# Artificial Intelligence and Healthcare Economics — Reader and Practitioner Edition

**Release V1.0**

This edition provides a simplified route through the current Digital Resource Companion. It is derived from the canonical source repository and contains reader-facing guidance, guided pathways, consolidated forms and workbooks, worked examples, reference guides, analytics navigation, catalogs, and the offline web companion.

## Begin

1. Open `00_START_HERE/START_HERE.pdf` or `00_START_HERE/START_HERE.html`.
2. Choose a task in `01_GUIDED_PATHWAYS/`.
3. Use the consolidated forms in DOCX, ODT, or printable PDF format, or the consolidated XLSX/ODS workbook, for institutional work.
4. Use worked examples before completing unfamiliar records.
5. Use the analytics guide only when the decision requires quantitative analysis.
6. Consult the canonical source repository for Python code, LaTeX, schemas, process source, and other technical materials.

The Reader and Practitioner Edition is a navigation and working edition. Stable resource identifiers and the canonical source repository remain controlling for source maintenance and technical integration.
