# Curated optional figure library

This library contains selected companion visuals for teaching, workshops, implementation planning, and framework explanation without duplicating the complete figure set of the printed book.

Each figure folder includes a concise README, a visual file, and accessibility text. The files are optional. A PNG is a raster preview, not an editable vector source. Use an SVG as an editable source only when the shapes, text, data, and reuse rights are fully controlled.
