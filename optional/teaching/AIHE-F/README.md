## Purpose

Optional compressed course plan, separate from the printed book.

## Folder contents

- `excel_workbook/` — the primary Excel workbook (`.xlsx`) for desktop Excel, Excel Online, or Google Sheets import.
- `editable_documents/` — Word templates or worked examples, where available.
- `printable_pdf/` — printable reference copies and worked examples, where available.
- `csv_data/` — blank and worked-example CSV exports of workbook tables, where available.
- `json_data/` — blank, worked-example, and schema JSON files, where available.
- `web_form/` — interactive HTML form, where available.
- `documentation/` — source README, alignment notes, and facilitator notes, where available.

## How to use this workbook

1. Open the workbook in `excel_workbook/`.
2. Save a project-specific copy before entering institutional data.
3. Review the source README and alignment notes in `documentation/`.
4. Use the blank CSV/JSON files if you need structured data import or export.
5. Do not enter identifiable patient data, credentials, private keys, or confidential contracts into uncontrolled copies.

## Excel or web use

- **Excel desktop:** open the `.xlsx`, enable editing if prompted, and save under a project name.
- **Excel Online / OneDrive:** upload the `.xlsx` to OneDrive or SharePoint, then open in Excel for the web.
- **Google Sheets:** upload the `.xlsx` to Google Drive and open with Google Sheets. Check formulas, formatting, and data validation after import.
- **LibreOffice Calc:** open the `.xlsx` directly and save as `.ods` only if your institution prefers OpenDocument formats. Verify formula and validation behavior after conversion.
