# Web Companion

Repository Release V1.0 adds a GitHub Pages layer for the current Digital Resource Companion.

## Main entry points

- `docs/index.html` — web companion home
- `docs/decision-stages.html` — ten-stage institutional decision navigator
- `docs/process/master-lifecycle.html` — master decision lifecycle
- `docs/process/index.html` — process-flow browser
- `docs/forms/index.html` — browser-editable core and reference resources
- `docs/resources.html` — searchable 190-resource catalog
- `docs/worked-examples.html` — interactive synthetic worked examples
- `docs/python-analytics.html` — searchable browser for all 39 Python modules
- `docs/bundles.html` — consolidated DOCX/ODT/PDF and XLSX/ODS resources

The canonical institutional records, workbooks, process files, code, and evidence remain outside the `docs/` presentation layer.
