Deterioration Alert Under Constrained Review Capacity

Decision question: Which alert threshold produces an operationally safe balance between missed deterioration and review burden?

Interpretation aid

Scenario

A fictional hospital evaluates an early-warning model for 250 patients per day. The rapid-response team can review no more than 35 alerts daily. Three thresholds have different sensitivity and specificity, so the team must evaluate the human-AI system rather than select the highest-sensitivity threshold in isolation.

Learning objectives

  • Translate sensitivity and specificity into daily workload.
  • Connect threshold selection to response capacity.
  • Quantify missed cases, false alerts, and unreviewed alerts.
  • Use abstention or staged review when no threshold is adequate.

Worked interpretation

Threshold A minimizes missed cases but produces an unmanageable alert load. Threshold B still exceeds review capacity. Threshold C fits current capacity but misses more cases. The initial pilot should therefore use a restricted high-specificity action zone with structured review of a gray zone, explicit missed-case monitoring, and a decision about whether response capacity must be expanded.
