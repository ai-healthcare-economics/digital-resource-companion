Chapter 15: Circularity-Adjusted Evaluation and Sustainable Value

Edge, Cloud, or Shared Diagnostic AI: Circularity-Adjusted Evaluation

Decision question: How does the preferred option change when conventional economic value is considered with environmental effects, residual value, resilience, equity, and rebound?

Scenario

A fictional diagnostic network compares edge deployment, commercial cloud hosting, and a shared regional platform. The options provide similar clinical benefit but differ in capital cost, annual fees, energy, water, carbon, residual value, latency, and dependency.

Learning objectives

  • Define a common functional unit and system boundary.
  • Keep conventional and circularity-adjusted results transparent.
  • Avoid double counting and arbitrary monetization.
  • Test sensitivity to carbon, water, residual value, and resilience.

Worked interpretation

Cloud has the lowest initial cost but the highest five-year operating cost and water burden. Edge has the strongest latency and residual value but requires more capital and local maintenance. The shared regional platform has the strongest overall balance in the synthetic example, conditional on data governance, interoperability, and exit rights. Conventional net benefit should be reported first, followed by disaggregated circular and environmental evidence.
