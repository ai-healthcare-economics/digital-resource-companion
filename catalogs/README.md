# Resource Catalogs

The catalogs are synchronized for release V1.0.

- `MASTER_RESOURCE_CATALOG.xlsx` and `.ods` support spreadsheet browsing.
- `MASTER_RESOURCE_CATALOG.csv` is the canonical tabular exchange file.
- `MASTER_RESOURCE_CATALOG.json` supports the Web Companion and software integration.
- Additional catalogs cover worked cases, Python modules, figures, and resource relationships.

The master catalog includes reader-facing discovery fields for level, audience, estimated time, inputs, outputs, prerequisites, frequency, recommended format, technical skill, guided pathway, browser availability, process availability, and default visibility. The Web Companion shows core, worked, case-method, and reference resources by default; advanced and technical source material is available through an explicit filter.

CSV, JSON, XLSX, and ODS editions are generated from the same current source and should not be edited independently.
