# Core Tools Pack

`AIHE_Core_Tools_V1.0.zip` is an optional convenience subset containing the consolidated core forms and workbooks in Microsoft and LibreOffice formats. It is derived from the V1.0 resource bundles and does not constitute a separate edition of the Digital Resource Companion.

For the complete practical distribution, use the Reader and Practitioner Edition. For source, computational, machine-readable, and publication materials, use the Canonical Source.
