# Consolidated Core-Resource Bundles

These release-V1.0 convenience editions collect the 24 canonical core resources into a single forms volume and a single workbook. They follow the current five-Part, fifteen-chapter book structure.

- `core_forms/` contains DOCX, ODT, and printable PDF editions.
- `core_workbooks/` contains XLSX and ODS editions.

The individual resource folders remain the canonical source. Before reusing a completed form, verify the stable resource ID, current version, chapter alignment, and release date.
