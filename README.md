# Artificial Intelligence and Healthcare Economics — Digital Resource Companion

**Release V1.0**

This repository accompanies *Artificial Intelligence and Healthcare Economics: Evidence, Value, Governance, and Sustainability*. It provides editable institutional records, worked examples, reference guides, computational resources, and publication source files aligned with the current five-Part, fifteen-chapter book.

## Start here

Most readers should begin with one of these entry points rather than opening the raw Chapter folders:

- **[Open `START_HERE.html`](START_HERE.html)** — guided reader and practitioner entry point that works from the downloaded ZIP.
- **[Open the Web Companion](docs/start-here.html)** — role- and task-oriented navigation, browser forms, worked cases, and analytics guidance.
- **[Choose a guided decision pathway](GUIDED_PATHWAYS.md)** — curated essential and optional resource sets for common institutional tasks.
- **[Download consolidated core forms](bundles/core_forms/)** — all 24 canonical core records in DOCX, ODT, and printable PDF formats.
- **[Download the consolidated core workbook](bundles/core_workbooks/)** — all 24 core records in one XLSX or ODS file.
- **[Explore worked examples](docs/worked-examples.html)** — synthetic cases that demonstrate the complete reasoning pathway.

The raw `chapters/`, `latex/`, machine-readable records, schemas, process-source files, and Python code are the canonical source layer. They are intended for advanced use, local adaptation, reproducible analysis, publication maintenance, and repository administration.

## Choose by goal

1. **Learn the approach** — begin with `START_HERE.html`, a worked example, and the aligned book chapter.
2. **Make an institutional decision** — use `GUIDED_PATHWAYS.md` or the Web Companion decision pathways.
3. **Use a template or workbook** — open the consolidated bundles or the browser forms.
4. **Run an analysis** — use `PYTHON_ANALYTICS.md` or the Python Analytics browser.
5. **Teach or facilitate** — use the Common Case-Analysis Method, worked examples, and teaching resources.

## Resource layers

- **Core resources** provide the principal recurring institutional records.
- **Worked examples** demonstrate problem definition, comparator selection, evidence, economics, governance, uncertainty, interpretation, and conditional recommendation.
- **Reference guides** distinguish the status and appropriate use of laws, standards, reporting guidance, appraisal tools, implementation frameworks, and decision aids.
- **Supplemental specialist tools** support tasks that require additional depth.
- **Python Analytics** provides reproducible scripts and notebooks for advanced quantitative work.
- **Technical source** includes LaTeX, JSON Schema, Mermaid, metadata, and other integration files.

## Responsible use

Create a governed local copy for operational work. Replace synthetic assumptions with authorized local evidence. Preserve the resource identifier, release, system and data versions, evidence cut-off, accountable owner, decision conditions, monitoring thresholds, next review date, and exit route. Do not place identifiable patient information, credentials, private keys, confidential contracts, or uncontrolled institutional data in public or ungoverned copies.
