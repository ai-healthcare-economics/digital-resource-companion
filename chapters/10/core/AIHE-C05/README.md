# AIHE-C05: Public Transparency and Communication Record

**Release:** V1.0
**Primary alignment:** Part IV, Chapter 10 — Governance, Accountability, and Institutional Risk

Define accurate, accessible communication about intended use, limitations, oversight, data, complaints, incidents, and alternatives.

## When to use this resource

Reader level: **Applied**. Typical completion time: **60–180 minutes**.

Required inputs: Defined decision problem, realistic comparator, local evidence, named owners, and applicable institutional requirements

Expected output: Versioned institutional decision record with conditions, monitoring, review date, and exit route

## Folder contents

- `README.md` — resource overview.
- `edit/docx/` — Microsoft Word files.
- `edit/odt/` — LibreOffice Writer files.
- `edit/xlsx/` — Microsoft Excel files.
- `edit/ods/` — LibreOffice Calc files.
- `data/` — CSV, JSON, and schema records.
- `flow/` — process map and machine-readable steps.
- `supp/` — supplemental specialist resources.

## Recommended sequence

1. Read the aligned book chapter and confirm that this is the smallest sufficient resource for the decision.
2. Create a governed local copy in the format suited to the work.
3. Replace synthetic or generic material with authorized, versioned local evidence.
4. Record assumptions, uncertainty, owners, safeguards, review dates, and trigger events.
5. Preserve the completed record and link it to the final institutional decision.

## Responsible use

The browser form is intended for orientation and structured drafting. Operational decisions should be preserved in a governed institutional record. Do not place identifiable patient information, credentials, private keys, confidential contracts, or uncontrolled data in public or ungoverned copies.
